# 🚗 Used Car Price Prediction

[![Open App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://used-car-price-prediction-ghrnr5aluflj9otfmzq7es.streamlit.app/)

**🌐 Live app:** [used-car-price-prediction-ghrnr5aluflj9otfmzq7es.streamlit.app](https://used-car-price-prediction-ghrnr5aluflj9otfmzq7es.streamlit.app/)

An end-to-end regression project that predicts used car prices from listing data (brand, model year, mileage, engine, accident history, etc.), scraped from cars.com.

The project walks through the full ML pipeline: data inspection, cleaning, duplicate removal, missing-value handling, feature engineering, feature selection, model comparison with cross-validation, hyperparameter tuning, and final evaluation.

## 📊 Dataset

- **Source:** [Used Car Price Prediction Dataset](https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset) (cars.com listings)
- **Rows:** 4,009 listings
- **Columns:** `brand`, `model`, `model_year`, `milage`, `fuel_type`, `engine`, `transmission`, `ext_col`, `int_col`, `accident`, `clean_title`, `price`

The raw CSV is included in [`data/used_cars.csv`](data/used_cars.csv).

## 🧠 Project Pipeline

1. **Initial inspection** — dtypes, missing values, duplicate check, cardinality per column
2. **Data cleaning** — parse `price`/`milage` out of messy text; regex-extract horsepower, engine size (L), and cylinder count from the free-text `engine` field
3. **Duplicate removal** — checked both before and after cleaning
4. **Missing value handling** — mode-fill for categoricals, brand-grouped median for numeric engine specs
5. **Outlier handling** — cap price at the 1st/99th percentile
6. **Feature engineering** — `car_age`, `mileage_per_year`, accident/clean-title binary flags, rare-category grouping for brand/color
7. **Feature selection** — drop redundant/high-cardinality raw text columns
8. **Preprocessing** — `ColumnTransformer` with `StandardScaler` (numeric) + `OneHotEncoder` (categorical)
9. **Model comparison** — 5-fold cross-validation across Linear Regression, Ridge, Lasso, Random Forest, Gradient Boosting, and XGBoost (scored on RMSE and R²)
10. **Hyperparameter tuning** — `GridSearchCV` on the best-performing model from step 9
11. **Evaluation** — RMSE, MAE, R² on a held-out test set, plus predicted-vs-actual and residual plots
12. **Feature importance** + model export (`.pkl`)

## 🌐 Streamlit Web App

**Try it live: [used-car-price-prediction-ghrnr5aluflj9otfmzq7es.streamlit.app](https://used-car-price-prediction-ghrnr5aluflj9otfmzq7es.streamlit.app/)**

A simple interactive web app (`app.py`) lets you enter a car's details and get a predicted price, plus a couple of exploratory charts.

**Run locally:**
```bash
pip install -r requirements.txt
streamlit run app.py
```

**Deploy for free on Streamlit Community Cloud:**
1. Push this repo to GitHub (steps below).
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub.
3. Click "New app" → select this repo → set main file path to `app.py` → Deploy.
4. Streamlit Cloud installs everything from `requirements.txt` automatically.

The app trains a quick fallback Random Forest on startup if no tuned model is found — but for the best results, run the tuning script once:

```bash
python tune_model.py
```

This runs `RandomizedSearchCV` (50 iterations × 5-fold CV) over an XGBoost model and saves the best one to `models/best_model.pkl`. Commit that file and the app will automatically use it instead of the fallback — no code changes needed. This only needs to be run once (or whenever you want to re-tune); the app never re-trains on every startup.

Note: this app's features are a simplified subset of the full notebook (no engine/horsepower extraction), to keep the input form beginner-friendly.
